#游戏化番茄钟计时计划🍅 瓶子专注 · Bottle Pomodoro

> 单文件番茄钟 Web 应用：种一棵陪你专注的树，把每 25 分钟都算数。
> 作者：瓶子满天星 · © 2026 · [MIT License](./LICENSE)

## 这是什么

「瓶子专注」是一个**单个 HTML 文件**就能跑的番茄钟应用——无需安装、无需服务器，把它丢进浏览器即可使用，所有数据都保存在本地浏览器（localStorage + IndexedDB）。

考虑到部分受限手机浏览器等环境的影响，源码在组织上采用模块化书写，也方便开发者阅读与二次开发。

它把「种树养成 + 段位成长」的轻量游戏化设计融进专注本身，让每一次专注都看得见成长：完成任务小树会长大、坚持久了段位会上升——专注从此有反馈、有温度。

## 主要功能

- **番茄钟计时**：25 分钟工作 + 短/长休息；休息活动骰子、模糊计时、白噪音、微休息提醒
- **自由专注**：正计时 / Flowtime 流式倒计时双模式，按 25 分钟折算番茄
- **沉浸式专注**：随机剧本冒险——星际 / 职场 / 仙侠 / 推理 / 警匪等主题，四个番茄一个章节故事，达成度决定结局（完美 / 失败 / 坏结局）
- **种树养成**：每完成一个番茄，树就长大一点；不同树种、场景、天气、光环特效、道具与商店
- **段位与成就**：从青铜到荣耀的段位体系、每日任务、赛季、排行榜、组队挑战
- **计划与习惯**：任务列表（截止日期 / 提醒 / 标签 / 预计番茄）、子任务、必做三件事、习惯打卡
- **目标与提醒**：每日番茄数目标（达成领奖励）、自定义定点提醒与定点休息
- **统计看板**：今日 / 周对比 / 趋势 / 热力 / 身心状态 / 完成质量 / 任务 / 节奏 / 段位 / 月度 / 年度
- **数据安全**：自动备份、JSON 导入导出、冗余历史清理（可勾选）、数据体检修复
- **外观**：浅色 / 蓝调（深色）模式，自动跟随系统深浅色，自定义壁纸与皮肤，电脑端侧栏自适应

## 快速开始

1. 下载 `index.html`
2. 用任意现代浏览器打开（Chrome / Edge / Safari / Firefox，手机桌面均可）
3. 点击「开始」，专注第一个番茄 🍅

> 提示：数据只存在当前浏览器里。换设备前请到「设置 → 数据备份与重置 → 导出全部数据（JSON）」，新设备再导入。

## 技术说明

- 零依赖单文件（HTML + CSS + JavaScript），无构建步骤
- 数据双源持久化：localStorage 镜像 + IndexedDB 主存
- 计时引擎：番茄倒计时、打断补偿、跨天/后台恢复、有效时长结算
- 源码结构：文件头部内置「文件结构总览」注释（按板块名搜索即可定位，行号会随版本漂移）
- 本产品含AI辅助开发内容
